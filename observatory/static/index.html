Observatory

One panel for all three fintech projects — launch them, watch them, open them

Repository Published page

Running means a request to the port came back — not that a process was spawned. Closing this panel does not stop the projects; the next launch adopts whatever is still up. A server this panel did not start is shown as such, because it cannot be stopped from here.

What each project has been asked to do

Counted by the projects themselves, inside the one function every request passes through, and polled from here. Timings cover the handler only, so a slow number means a slow engine rather than a slow network.

What a project printed

Each project writes to its own file under observatory/state/logs/. When a start fails, this is where it says why.
